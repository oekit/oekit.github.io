快速开始

三种起步姿势：单个微库、可观测门面组合、HTTP/RPC 全栈骨架。

三种起步姿势

姿势一：只要一个微库

oekit 的 16 个基础工具包合在 oekit/pkg 一个 module 里，Go 按包编译，import 哪个用哪个：

go get github.com/oekit/pkg@latest
package main

import (
    "fmt"

    "github.com/oekit/pkg/errors"
    "github.com/oekit/pkg/stringx"
)

func main() {
    if err := doSomething(); err != nil {
        // nil-safe 包装 + kv 关联字段
        err = errors.Wrap(err, "do something failed", "user_id", 42)
        fmt.Println(errors.Cause(err))
    }
    fmt.Println(stringx.Pluralize(3, "module")) // 3 modules
}

姿势二：可观测门面组合

go get github.com/oekit/logx github.com/oekit/tracing github.com/oekit/metrics github.com/oekit/registry

logx 是全矩阵的日志门面（详见 日志指南）， tracing 提供 OTel 接入与 trace_id 上下文，metrics 提供 Prometheus Registry， registry 提供服务注册发现抽象与 Nacos 实现。

姿势三：HTTP / RPC 全栈骨架

# HTTP 服务：中间件栈 + Hertz 运行时 + 应用引导
go get github.com/oekit/middleware github.com/oekit/hertz github.com/oekit/bootstrap
# RPC 服务：Kitex 生态
go get github.com/oekit/kitex github.com/oekit/nns github.com/oekit/nns-endpoint

全栈骨架参考 HTTP 服务指南 与 RPC 服务指南。

模块地图

层模块说明

L2data · gorm · redis · httpx · timertask · middleware · nns · nns-endpoint缓存、SQL/CRUD、Redis、HTTP 客户端、定时任务、中间件栈、服务治理
L3bootstrap · handler · hertz · kitex · workflow应用引导、CRUD handler、Hertz/Kitex 运行时、流程编排
