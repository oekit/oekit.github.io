Open Easy Kit — 开源 · 易用 · 工具集合

22 个独立发版的 Go 模块：微工具库、日志与可观测门面、注册发现、HTTP/RPC 生态、应用引导。 按需取用一个，或组全套骨架；每仓独立 SemVer、独立 CI、零强制捆绑。

go get oekit 浏览全部仓库 →

Open开源

全部 MIT 协议，源码即文档。38 个仓库全部公开、可审计、可 fork——不锁平台，不玩闭源阉割。

Easy易用

每个模块只做一件事，import 即用；微库零依赖或至多一条内部依赖，不会为了一个字符串函数拖进整个框架。

Kit工具集合

从 errors/stringx 微库到 Hertz/Kitex 生态适配器，同套规范同套接口分层，既能单点取用也能组全套骨架。

指南 从单个 import 到生产级服务，逐层展开

01快速开始

三种起步姿势：单微库、门面组合、全栈骨架；模块地图。

02日志（logx）

接口分层、Delegating 懒解析、多后端替换、Sink 多目标、caller 归属。

03错误处理

Wrap/Cause、BizError 双码、统一 Fail 出口；类型同一性红线。

04HTTP 服务全栈

config→gorm→crud→中间件栈→nns 注册→bootstrap 生命周期。

05RPC 服务（Kitex）

治理热更三条纪律、BizError 桥接、元信息透传、端点熔断重试。

06可观测性

metrics/tracing/traceid 三件套；OTel 与 OpenTracing 二选一。

07迁移指南

三段历史路径映射、API 变更对照、一条命令改写 import。

快速开始 按需取用，一个 import 就能跑

# 微工具集（16 合 1）
go get github.com/oekit/pkg@latest

# 日志 + 追踪 + 注册发现
go get github.com/oekit/logx github.com/oekit/tracing github.com/oekit/registry

# HTTP 服务全家（中间件栈 + Hertz 运行时）
go get github.com/oekit/middleware github.com/oekit/hertz
package main

import (
    "github.com/oekit/logx"
    "github.com/oekit/pkg/stringx"
)

var svcLog = logx.WithService("my-service")

func main() {
    svcLog.Info(stringx.Pluralize(3, "module"), "version", 1)
}
